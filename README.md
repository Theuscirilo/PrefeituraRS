# 🎥 Sistema de Orçamento de Gravação - Prefeitura

Este projeto é uma aplicação interativa desenvolvida com [Streamlit](https://streamlit.io/) para facilitar a solicitação e a gestão de orçamentos de gravação por parte de prefeituras ou órgãos públicos.

## ✨ Funcionalidades

- **Solicitação de Orçamento**: Vereadores e Prefeitos podem preencher um formulário para solicitar orçamentos de gravação em locais públicos ou viagem a fora.
- **Cadastro de Informações**: Coleta nome, contato, tipo de filmagem, uso de drone e local desejado.
- **Painel Administrativo**: Área restrita com autenticação para que funcionários da prefeitura visualizem todas as solicitações.
- **Exportação de Dados**: As solicitações podem ser baixadas em formato CSV para fins de relatório ou controle interno.
- **Modo Seguro**: Acesso à área administrativa protegido por senha.

## 🛠 Tecnologias Utilizadas

- Python
- Streamlit
- Pandas
